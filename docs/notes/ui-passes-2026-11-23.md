# Three UI/UX passes per platform (2026-11-23)

Jack asked for three UI/UX runs for each platform: an agent scoring UI and UX separately (1–10),
with the website's desktop and phone scored apart, then fixing what it found. Each pass had an
independent reviewer per platform (screenshots only, no code; briefs in the session scratchpad)
and a fixer: website desktop (headless Chromium 1440×900), website phone (390×844 with touch),
and the Android app (the `sheddex` emulator running the debug build on Metro). Pass focus:
1 first look and the core (landing, dashboard, Shed Log, Library, chart editor, a few tools),
2 every tool in depth, 3 everything else (Notes, Lessons, Community, Files/PDF, Account) and a
sweep. Two test accounts (`uxpass@soniroll.test` for the website, `uxandroid@soniroll.test` for
the phone) so reviewers' writes didn't collide.

## Bugs found beyond polish

- **Website: an open page wrote its old copy over changes made elsewhere.** `lib/syncedStore.ts`
  took the account's value once per session and ignored later server values, so a page left open
  (which saves tool time every minute) wiped a Shed Log tick made on the phone. Now a newer server
  value replaces the cache unless a local edit is waiting or our own write hasn't echoed back
  (5 s). Found by the Android fixer while chasing "ticks don't stick".
- **Website: edits made just before leaving a page were lost.** Synced writes wait 600 ms; a page
  that navigated back to an earlier full page load went into the back-forward cache with its timer
  frozen (deleting a tune opened by a full page load "came back"). Pending writes are now sent on
  `pagehide` / hidden. The phone app now sends waiting edits when it goes to the background.
- **PDFs: scanned books opened with every page blank** — pdf.js had no wasm decoders (JBIG2 /
  JPEG 2000). Now served from `public/pdfjs/<version>/` (`scripts/copy-pdfjs-assets.mjs`).
- Chord chart editor didn't read common spellings (Cmaj7, Dm7b5, dim7) — `chordAliasToIreal` in
  `packages/core/iRealPro.ts`; Guess the Interval spelled some intervals wrongly (`spellInterval`
  in `packages/core/noteSpelling.ts`, web and phone).
- Phone: a Stop tap in Guess the Chord/Progression typed into the next question; the recording bar
  said "Playing" with no stop; sheets slid under the status bar with the keyboard open; signing out
  left the previous account's routine screens with live buttons.
- Rhythm Section: switching the tune source changed the style and tempo (the default style
  depended on whether a chart was picked yet).
